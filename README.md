# Fixture Flow Website

## Setup
1.  This site is designed to be hosted on **GitHub Pages**.
2.  Go to repository Settings -> Pages.
3.  Source: Deploy from a branch.
4.  Branch: `main` / `root`.

-   `index.html`: Main landing page.
-   `assets/`: Images and screenshots.
